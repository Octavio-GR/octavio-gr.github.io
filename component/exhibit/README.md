# Exhibit Component

## Purpose

Provide a reusable structure for every Toroide Exhibit.

An Exhibit is not documentation.

An Exhibit is an observable demonstration.

---

## Every Exhibit must contain

- Title
- Status
- Question
- Observation
- Evidence
- Current Status
- Link to complete documentation

---

## Every Exhibit should

- Be readable in under one minute.
- Demonstrate something observable.
- Link to supporting documentation.
- Avoid unnecessary explanation.

---

The README remains the complete source.

The HTML is only the public presentation.
