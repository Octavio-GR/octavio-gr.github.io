# EX-001 — Toroide Construction

## Question

How can a digital project make its architectural evolution publicly observable from inception?

## Observation

Traditional portfolios often present a polished final product while concealing much of the process behind it. Toroide treats construction itself as an observable artifact, making architectural decisions, documentation, and structural evolution available as verifiable project evidence.

## Architecture & Implementation

- **Public Observability**: Core concepts, directory hierarchies, documentation, and architectural decisions are exposed through the repository structure.
- **Documentation-First Workflow**: Architectural decisions and project principles are documented before or alongside implementation, providing explicit intent behind structural changes.
- **Static Artifacts**: The exhibit is implemented using native web fundamentals and does not require a client-side framework or build step to render its content.

## Verification

Inspect the project directory tree, documentation, and historical Git commits to trace how architectural foundations, decisions, and implementation evolved over time.
