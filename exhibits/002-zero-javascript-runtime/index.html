EX-002 — Zero JavaScript Runtime

Partially verified

Question

Can complex layout and responsive behavior exist without client-side scripting?

Observation

Modern CSS capabilities (Grid, Flexbox, Container Queries, calc()) eliminate the need for JavaScript in structural layout and basic interactivity.

Evidence

  • Core layout does not require first-party JavaScript.
  • Responsive adaptation handled entirely by CSS math functions.
  • Layout is delivered through HTML and CSS without requiring a first-party layout script.
  • No client-side hydration is required for the exhibit's core content or navigation.

Current Status

The exhibit's core content, layout, and navigation do not require first-party JavaScript. Third-party scripts, if present, are outside this claim.
