## Status Semantics

- **IN PROGRESS** — the report declares work ongoing.
- **COMPLETED / VERIFIED** — the report declares completion and verification.
- **COMPLETED WITH LIMITATIONS** — the report explicitly retains limitations; completion must not be interpreted as unrestricted validation.
- **VERIFIED — TEXTUAL INTEGRITY CHECKS PASSED** — verification is limited to the checks described in the verification record.
